# AgroFlight online

Análise de voos DGPS (AgNav) da aviação agrícola — mapas de taxa, velocidade,
sobreposição, falhas e altura sobre o solo, relatórios em PDF e dashboard.

Este repositório guarda só o site publicado (GitHub Pages). Os dados ficam no
Supabase e só aparecem depois do login; cada navegador guarda uma cópia para
abrir rápido e funcionar sem internet.
